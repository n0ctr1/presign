# Tooling feedback

Each partner track we submit to asks for feedback on their tooling, and Ledger
judges it alongside the code. These files are written **as we go**, on the day
the observation happens, not assembled on the last evening — a note written a
week later has already lost the detail that made it useful.

One file per partner. Each entry is dated, says what we were trying to do, what
happened, and where the friction was. Praise and complaints get the same
treatment: an entry that only says "worked great" is not feedback.
