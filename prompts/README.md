# Specification prompts

These are my specifications for the project, in the order they were given —
what was to be built, what was decided, what was ruled out. They are the
instructions an AI coding agent worked to, not a record of what it produced.

They are not a transcript: the working sessions run to hundreds of megabytes
and contain secrets, device output and dead ends. What is kept is the
instruction.

`0001` is the original specification. The file it was distilled from is
timestamped 5 September 14:27 UTC; the first commit in this repository is
15:18 the same day. Everything after it is a phase.

See [`../docs/AI_USAGE.md`](../docs/AI_USAGE.md) for how these were used, and
for the three design decisions that were changed by what the test runs
returned.
